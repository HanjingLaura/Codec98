# Codec98 — 话术编解码器（多领域版）

> Codec = **co**der + **dec**oder：把对方的话解码成人话，把你的真心话编码成得体表达——并且越用越懂对方。

一个复古 Win98 世界观 + 像素游戏层的黑客松 demo。零依赖 Node 服务，`node server.js` 开箱即跑；配上百炼 API Key 就是真 LLM 驱动，不配 key 也有本地兜底。

---

## 一、产品定位

**解决的问题**：中文语境里大量高频对话是"话里有话"的——老板的「再想想」、对象的「我没生气」、甲方的「预算有限但曝光机会很大」。听不懂潜台词的代价是真金白银的（错过跳槽时机、把对象气炸、被白嫖方案）。

**产品做三件事**：

1. **解码**：把对方的原话翻译成潜台词，并直接给出可复制发送的回复草稿（三档语气可选）
2. **加密**（反向翻译）：把你的真心话（往往情绪化、有杀伤力）改写成立场不变但得体的表达
3. **越用越准**：针对具体的人建档案，你的每次纠错都会进入 TA 的专属语料库，成为下次解码的最高优先级参考

**三条设计红线**（这是产品不油腻、不做恶的关键）：

- 永不输出百分比置信度——潜台词本质是概率游戏，假装精确就是欺骗
- 玩笑只出现在仪表盘、视觉、语气档名里，**解读结论本身永远专业克制**，不阴谋论
- 回复草稿必须在所有解读下都安全——即使潜台词猜错了，照着回也不翻车

## 二、三个领域

桌面顶部是三个 Win98 快捷方式图标，点击即切换整个"程序"（标题栏、仪表盘、人物类型、鉴定题全部跟着变）：

| 领域 | EXE | 仪表盘 | 目标人物类型 |
|---|---|---|---|
| 🖥️ 职场版 | BOSS_DECODER.EXE | 🫓 画饼指数 / ⚠️ 甩锅风险 | 画饼型·甩锅型·委婉型·直接型·谜语人 |
| 💘 恋爱版 | LOVE_DECODER.EXE | 🚩 红旗指数 / 🍬 糖分浓度 | 口是心非型·冷处理型·暗示型·直球型·忽冷忽热型 |
| 🪤 甲方版 | CLIENT_DECODER.EXE | 🪤 白嫖风险 / 🔁 改稿预警 | 白嫖型·砍价型·模糊型·爽快型·拖延型 |

每个领域自带：5 类人设（像素头像+称号）、5 题人物鉴定测试、雷达图维度、一套手写语料库 few-shot、独立的系统提示词。

**加新领域 = 在 `data/domains.json` 加一段配置 + 一个语料 JSON，零代码改动。**

## 三、核心功能

### 3.1 正向解码（话术 → 人话）
- 先诚实判断是否字面意思：日常事务性表述会判定「无言外之意」，不制造焦虑
- 有言外之意时给 1-2 个解读（第一个最可能），每个解读附**可直接复制发送的回复草稿**
- 两个解读难分高下时，给「探口风建议」：一个低成本试探动作，看对方反应再定——这是高手的真实做法

### 3.2 反向加密（人话 → 得体表达）
输入真心话（如「这个需求就是垃圾」「你再这样我们就分手」），保留立场内核、只换包装。反对还是反对，拒绝还是拒绝，但从"抱怨者"变成"操心项目的人"。

### 3.3 语气滑块（三档）
🛡️ 稳妥 → 不卑不亢 → 🔥 勇。同一个解读，三档给出的回复草稿从"圆滑留余地"到"敢于当面对质"，现场拖动滑块立刻可见变化。

### 3.4 人物档案卡（像素游戏层）
「＋建立新档案」→ 5 题鉴定 → 像素角色卡翻转登场：类型称号、雷达图、口头禅、研究进度 Lv.1-9。档案跟随领域隔离（恋爱版看不到你的老板档案）。

### 3.5 反馈闭环（产品的护城河）
每次解码后可点「👍 翻译准 / ✏️ 不准我来纠正」。纠错内容进入该人物的专属语料库，在 prompt 中以**最高优先级**注入（"用户亲自确认的纠错案例，比任何通用规律都重要"）。并排对比模式可直观看到通用翻译 vs 吸收了纠错记录的专属翻译的差距。

## 四、启动

**零依赖，无需 `npm install`**，装了 Node.js（≥18，需要内置 fetch）就能直接跑。

### Windows

```bat
:: 1. 安装 Node.js（如果没装）：https://nodejs.org 下载 LTS 版，一路下一步
::    验证：打开 cmd 或 PowerShell，输入 node -v 能看到版本号即可

:: 2. 进入项目目录并启动
cd %USERPROFILE%\Desktop\Codec98
node server.js

:: 3. 浏览器打开 http://localhost:3210
```

停止服务：在运行窗口按 `Ctrl + C`。

### macOS

```bash
# 1. 安装 Node.js（如果没装）
brew install node        # 或到 https://nodejs.org 下载安装包
node -v                  # 验证 ≥ v18

# 2. 进入项目目录并启动
cd ~/Desktop/Codec98
node server.js

# 3. 浏览器打开 http://localhost:3210
open http://localhost:3210   # 也可以直接用命令打开
```

停止服务：在终端按 `Ctrl + C`。

启动日志会打印当前模式：`LLM在线（dashscope）` 或 `演示降级（无API key，本地兜底）`。

### 接入真实 LLM（可选）

编辑项目根目录的 `.env` 文件，填入百炼 API Key。没有该文件就从模板复制一份：

```bat
:: Windows
copy .env.example .env
notepad .env
```

```bash
# macOS
cp .env.example .env
open -e .env    # 或 vim / nano
```

`.env` 配置项：

```bash
DASHSCOPE_API_KEY=sk-xxx    # 阿里云百炼 API Key（bailian.console.aliyun.com → API-KEY管理）
MODEL_NAME=qwen-plus        # 可换 qwen-max / qwen-turbo
ANTHROPIC_API_KEY=          # 备选；设了百炼时优先走百炼
PORT=3210                   # 3000 常被占用，默认避开
```

改完 `.env` 重启 `node server.js` 生效。

### 常见问题

- **`node` 不是内部或外部命令 / command not found**：Node.js 没装或没进 PATH，重装后重开终端
- **`EADDRINUSE` 端口被占用**：改 `.env` 里的 `PORT`（如 3211）再启动
- **页面打开是空白**：确认终端里服务还在跑、地址端口和 `.env` 里 `PORT` 一致

**LLM 优先级：百炼(DashScope) > Anthropic > 本地演示兜底。**
不配 key、断网、API 报错，都会自动降级到内置演示响应器（预设剧本 + 语料库模糊匹配），demo 永远能跑。界面右下角角标如实标注当前来源：`⚡ LLM 实时解码（dashscope）` 或 `⚙ 演示模式输出`。

## 五、Demo 演示剧本（四幕 + 彩蛋）

1. **建立信任**：职场版通用模式输入「这个方案你再想想，不着急」→ 双解读 + 回复草稿 + 画饼/甩锅血条；再输入「明天上午十点会议室开会，记得带上电脑」→ 系统判定"无言外之意"（证明它不瞎编焦虑）
2. **好玩登场**：切「加密模式」输入「这个需求就是垃圾，做了也没人用」；拖语气滑块到「勇」看三档变化
3. **核心叙事**：「＋建立新档案」做 5 题鉴定 → 像素角色卡翻转登场；勾选「并排对比模式」看通用 vs 专属的差距
4. **进化闭环**：选中预埋的「张总（Lv.6，10 条语料）」，输入「年底看情况，你先好好干」→ 专属解码直接引用纠错记录（"看情况=没戏，去年年终奖是一箱橙子"），而通用模式只能给泛化解读；点「✏️ 不准，我来纠正」演示反馈写回、等级提升
5. **彩蛋（平台化故事）**：点 💘 恋爱版图标，输入「我没生气」——同一套引擎、完全不同的人格，30 秒讲完"这不是一个工具，是一个可横向复制的解码平台"

## 六、技术结构

```
server.js                  零依赖 HTTP 服务 + API 路由
lib/env.js                 零依赖 .env 加载器（不覆盖已有环境变量）
lib/prompt.js              Prompt 组装器（全项目技术核心）
lib/llm.js                 百炼/Anthropic 调用 + 演示降级响应器
lib/store.js               JSON 数据读写 + 领域配置加载
data/domains.json          领域配置（标题/仪表/类型/鉴定题/雷达维度/系统提示）
data/general_corpus.json   职场语料：5 类老板 手写 few-shot
data/corpus_romance.json   恋爱语料：5 类 TA 手写 few-shot
data/corpus_client.json    甲方语料：5 类甲方 手写 few-shot
data/bosses.json           目标人物档案
data/corpus.json           专属语料/纠错记录
public/                    98.css 复古 OS 前端（index.html / app.js / custom.css）
```

**Prompt 组装顺序**（`lib/prompt.js`）：

```
领域系统指令（含输出 JSON schema、设计红线）
→ 领域通用语料包 few-shot（按人物类型筛选）
→ 目标人物人设（类型、口头禅、经典语录）
→ 用户亲自确认的纠错案例（标注为最高优先级参考）
→ 补充背景（用户填写的上下文）
→ 语气档位
→ 待处理原话
```

**演示兜底的实现**（诚实说明，答辩被问到时别含糊）：预设剧本按领域关键词正则匹配 + 语料库字符重叠度模糊匹配（阈值 0.45）+ 通用兜底话术。不是 embedding 也不是余弦相似——黑客松规格，够用且永不掉线。

## 七、API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/domains | 领域配置列表 + 当前 LLM provider |
| POST | /api/translate | `{domainId, text, context?, direction: forward\|reverse, tone: safe\|neutral\|brave, bossId?, compare?}` |
| GET | /api/bosses?domainId=x | 该领域的人物列表（含 Lv 与语料数） |
| POST | /api/bosses | 创建档案（鉴定测试提交，带 domainId） |
| POST | /api/feedback | `{bossId, 原话, AI翻译, 准确, 纠正内容?}` 反馈闭环 |
| GET | /api/bosses/:id/corpus | 某人物的研究记录 |
